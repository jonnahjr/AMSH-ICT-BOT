Place an Ethiopic-capable TrueType font here if Amharic text must appear in generated PDFs.

Expected default filename: NotoSansEthiopic-Regular.ttf

Set PDF_FONT_PATH in .env to the exact font file path. Obtain the font from an official/trusted distribution and comply with its license. The bot's Telegram prompts support Amharic without this font; this font is only for PDF rendering.
